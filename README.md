### 📂 Proyectos Destacados

#### 🛠️ [Pipeline de Ingesta: PDF a Data Estructurada](https://github.com/Naiiki-YG/Analisis-Facturas)
Desarrollo de un motor de extracción en **Python** que procesa documentos no estructurados (PDF), realiza limpieza avanzada con **Pandas** y normaliza los datos para su carga en entornos relacionales. Incluye un análisis exploratorio (EDA) detallado en Jupyter Notebook para asegurar la integridad de la información.

#### 📊 [Automatización de Bitácoras Operativas (SOC)](https://github.com/Naiiki-YG/data-pipeline-automation-gcp-n8n)
Arquitectura serverless en **GCP** utilizando **n8n** y **Docker**. El flujo automatiza la recepción de datos desde Gmail, el almacenamiento en Cloud Storage y la carga final en **BigQuery**, integrando **Gemini** para la categorización inteligente de incidentes.

#### 📝 [Generador de Datasets de Facturación](https://github.com/Naiiki-YG/Naiiki-YG-Generar-factura-para-analisis-simple)
Script especializado para la creación de datos sintéticos financieros. Diseñado para realizar pruebas de carga en bases de datos y validar dashboards sin exponer información sensible.
